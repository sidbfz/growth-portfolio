# 3D objects in the hero's torn head

All five are 800×800 transparent WebP files. Each object is cropped to its silhouette and scaled so its longest side is 736px (92%), then centred. That keeps their sizes comparable, so the hero CSS sets each one's size.

## Laptop

3dicons has no laptop. This one was modelled in three.js 0.160 (rounded boxes, clearcoat physical material, RoomEnvironment studio lighting, ACES tone mapping) and rendered on a transparent background. Its palette is sampled from the 3dicons "Computer" icon (https://3dicons.co/icons/5f20be-computer): a teal-to-blue body and a peach screen. Saturation was then lifted by 12% to match the other icons. If it ever looks out of place, the 3dicons Computer icon (also CC0) is a drop-in replacement.
